# Proyecto Vite 2

Proyecto académico para actualizar la web de Procurador Tomás mediante Vite y componentes JavaScript.

## Estado actual

Entorno preparado con Vite 8.3.3. El desarrollo de la web y sus componentes está pendiente.

## Requisitos del ejercicio

- Navbar independiente con logo, enlaces Inicio, Servicios y Contacto, menú móvil y estilos internos.
- Componente Section que reciba id y contenido.
- Montaje de los componentes desde src/main.js mediante app.append(...).
- CSS global mínimo en src/styles/estilos.css, si es necesario.

## Referencias

- Web original: https://www.procuradortomas.com/
- Repositorio: https://github.com/CACHUMBAS/PROYECTO-VITE-2

## Entorno de desarrollo

Node.js 24.16.0 y npm 11.13.0 disponibles en el equipo. Vite está instalado como dependencia de desarrollo del proyecto.

- npm ci: instalar las dependencias exactas desde package-lock.json al descargar el repositorio.
- npm run dev: iniciar el servidor de desarrollo.
- npm run build: generar la versión de producción.
- npm run preview: previsualizar la versión compilada.

Los comandos de desarrollo y compilación se utilizarán cuando se creen index.html y los archivos de src/.
